# Inbox

Drop external material here (e.g. an insights file from another project). The next session that sees a file here will:
1. Read it in full and pull out the lessons that apply to Lumen Core's process, architecture, or design.
2. Fold those into the right places (`CLAUDE.md`, `docs/01`, `docs/04`, `docs/03`), always phrased as decisions or rules, never pasted wholesale.
3. Write a short summary of what it adopted and rejected (with reasons) to `docs/09`, then move the file to `docs/archive/`.
